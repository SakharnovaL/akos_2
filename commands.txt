listener = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
AF_INET - интеренет сокет по протоколу IPv4, AF_INET6 - по протоколу IPv6, AF_IPX - для IPX (хз что это), AF_UNIX - Unix-сокеты
SOCK_STREAM - в качестве транспртного протокола используется TCP (гарантирует доставку сообщений именно в том порядке, в котором они были отправлены). вместо него можно использовать SOCK_DGRAM - в качестве транспртного протокола используется UDP (возвращает сообщение сразу по прибытии без проверки, обработки и подтверждений према)

SERVER
listener.bind((IP, PORT))
bind - привязка к адресу

listener.listen(0) - слушаем подключения, 0 - количество одновременно ожидающих обработки подключений (5 обычно достаточно)

connection, address = listener.accept()  
accept на выходе дает кортеж, где через первое значение сервер общается с клиентом, а второе значение - кортеж с сетевым адресм клиента

для организации многопоточности, те 500 миллиардов серверов принимаю 500 миллиардов клиентов, есть три способа: процессы (создают копии самого сервера), потоки (выполняются в одном процессе) и select с аналогами (тоже выполняются в одном потоке) 

ПРОЦЕССЫ (единсвенный плюс - выполняются параллельно):
os.fork - какая-то функция, которая помогает организовать многопоточность, но она это делает, создаваяя 100500 миллиардов копий нашей основной программы, что делает ее максимально долгой и ресурсозатратной. и плюсом она работает только в Unix-подобных системах
есть еще multiprocessing, но тоже фигня какая-то сложная
